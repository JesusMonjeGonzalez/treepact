# ADR 0012: No CI/CD Scope

- Status: accepted
- Date: 2026-08-11

## Context

CI/CD platforms already solve remote pipelines, publication, deployment, and branch enforcement. TreePact's wedge is local pre-merge supervision.

## Decision

Do not implement CI workflows, hosted runners, branch protection, deployment, release automation, or pipeline dashboards.

## Consequences

Verification is a versioned local campaign. TreePact may export evidence for humans or future consumers but does not become a software-delivery platform.
