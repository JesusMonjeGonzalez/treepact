# Changelog

## 0.2.0 — 2026-08-31

### Added

- Read-only `treepact review` projections for run lists and run details.
- Strict schema-versioned JSON validation for review documents, gates, artifacts
  and event-chain metadata.
- Hearthia integration documentation and the public review schema.

### Changed

- The package and CLI version are now `0.2.0`.
- The source suite now contains 183 project tests; the historical M9 campaign
  remains documented separately at 170 tests.

## 0.1.0 — 2026-08-11

- Initial standalone TreePact source baseline with Pact validation, isolated
  worktrees, evidence gates and offline-verifiable decision bundles.
